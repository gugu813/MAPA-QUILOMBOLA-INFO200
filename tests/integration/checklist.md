# Checklist de Demonstração do Fluxo Completo

- [ ] 1. Abrir o terminal dentro da pasta `backend/` e rodar: `npm install` e depois `npm start`.
- [ ] 2. Confirmar que a mensagem `Servidor rodando em http://localhost:3000` apareceu no terminal.
- [ ] 3. Abrir o arquivo `frontend/index.html` com a extensão **Live Server** no VS Code.
- [ ] 4. Verificar se os pinos de teste apareceram automaticamente no mapa no Maranhão.
- [ ] 5. Preencher o formulário da barra lateral com uma nova comunidade e clicar em **Salvar no Mapa**.
- [ ] 6. Verificar se o mapa atualiza sozinho exibindo o novo pino cadastrado.
